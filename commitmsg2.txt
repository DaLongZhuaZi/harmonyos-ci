fix(ci): 消费方模板加防呆 guard + 默认 tag 对齐 api26r

问题: build.yml / sign-and-release.yml 是给 HarmonyOS 应用工程仓库用的模板,
但它们也位于本仓库的 .github/workflows/ 下。本仓库只有镜像与文档、没有应用工程,
于是每次 push 都会触发 Build HAP 并因找不到 build-profile.json5 而失败,
把本仓库的 Actions 页面刷成红色(见 run 35584685279)。

修复: 两个模板各加一个 guard job, 先判定仓库根是否存在
build-profile.json5 + oh-package.json5:
- 是工程 -> 正常构建
- 不是工程 -> 后续 job 全部 skipped, 整个 run 为 success, 并输出 notice 指引
这样模板留在本仓库也不会误报失败, 复制到应用工程后行为不变。

同时把模板默认镜像 tag 由 api26 改为 api26r, 与 README / docs 的推荐一致
(api26 是 Beta1, 新工程应用 API 26 正式版 api26r)。
